Muse tests a causal compatibility hypothesis.

Muse proposed a bounded hypothesis. ProtocolSmith executed baselines, correct-parameter requests, and swapped-name negative controls. The mapping is accepted only when all six deterministic outcomes agree.

Model-designed proposal

Does page_size map to limit?

Candidate hypothesis: legacy query param page_size maps to modern query param limit as limit = page_size, so page_size=1 on GET /v1/customers/{id}/orders should correspond to limit=1 on GET /v2/customers/{id}/orders, pending confirmation from controls where baseline and swapped names both return 2 items while correct name truncates to 1 item

Causally confirmed · 6/6 controls passed
Controlled finding

Version-specific parameter mapping confirmed

The candidate mapping was tested with positive and negative controls. Each API returned two items at baseline, ignored the other version’s parameter name, and returned one item only when given its proposed version-specific parameter.

View rule

Convert integer cents to decimal string dollars nested under amount: amount.value = format(total_cents/100, '.2f') as string; amount.currency observed as 'USD' with no legacy equivalent; reverse: total_cents = int(round(float(amount.value)*100))

Truncate ISO8601 datetime to date: created = created_at[0:10] (YYYY-MM-DD); time component dropped, reverse requires midnight UTC reconstruction only if needed
